# Screenshots & Assets Guide

Save your application screenshots in this directory using the following names to make them display automatically in `README.md`:

| Filename | Description | Suggested Dimensions |
|:---|:---|:---|
| `logo.png` | Project logo or branding icon | 512x512 px (PNG with transparent bg) |
| `dashboard-owner.png` | Executive / Owner Dashboard | 1920x1080 or 1440x900 px |
| `dashboard-hr.png` | HR & Talent Specialist Dashboard | 1920x1080 or 1440x900 px |
| `recruitment-board.png` | ATS Kanban Board (candidates in stages) | 1920x1080 or 1440x900 px |
| `onboarding-pipeline.png` | Onboarding / Offboarding workflows | 1920x1080 or 1440x900 px |
| `member-profile.png` | Employee profile, salary history, tabs | 1920x1080 or 1440x900 px |
| `custom-fields.png` | Custom fields builder / playground modal | 1920x1080 or 1440x900 px |
| `calendar-timeoff.png` | Calendar with leaves, events, time-off requests | 1920x1080 or 1440x900 px |
| `notifications.png` | Notification center & quick actions dropdown | 1920x1080 or 1440x900 px |

> **Tip**: For best visual quality on GitHub, compress PNG screenshots using tools like [TinyPNG](https://tinypng.com/) or export as WebP/optimized PNG.
